1. What is Python?

Python is a high-level programming language used in web development, automation, data analysis, artificial intelligence and machine learning.

2. Variables and Data Types

Variables store values. Common data types include integers, floats, strings and booleans.

name = "Gopi"
age = 21
percentage = 85.5
is_student = True

print(name)
print(age)

3. Conditional Statements

Use if and else to make decisions in a program.

marks = 75

if marks >= 40:
    print("Pass")
else:
    print("Fail")

4. Loops

Loops repeat a block of code. Python provides for and while loops.

for number in range(1, 6):
    print(number)

5. Functions

Functions organize reusable code.

def add(a, b):
    return a + b

result = add(10, 20)
print(result)

6. Lists

A list stores multiple items in a single variable.

skills = ["Python", "SQL", "Excel"]

for skill in skills:
    print(skill)
